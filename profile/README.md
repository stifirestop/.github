## 👋 Welcome to STI's Software Development Organization

We're the software development team at **Specified Technologies Inc.**, a leader in firestop systems and through-penetration solutions. Our mission is to build innovative software tools that help architects, engineers, contractors, and building professionals design safer buildings.

### 🎯 What We Build

- **Mobile Applications** – iOS and Android apps for field professionals
- **Web Applications** – Browser-based tools for design, estimation, and documentation
- **Microservices** – Scalable cloud services powering our digital ecosystem
- **Revit Plugins** – BIM integration for fire protection design
- **APIs & SDKs** – Platform services for internal and partner integrations

## 🏗️ Our Tech Stack

### Backend
- **Languages:** PHP, Node.js
- **Frameworks:** Laravel
- **Databases:** MSSQL, MySQL, MongoDB, Redis
- **Cloud:** Microsoft Azure

### Frontend
- **Web:** React, TypeScript, Vue, Vite
- **Mobile:** Kotlin, Swift, React Native
- **UI:** Tailwind CSS, Bootstrap

### DevOps & Tools
- **CI/CD:** GitHub Actions
- **Containers:** Docker
- **Auth:** Auth0
- **Monitoring:** Sentry, Application Insights
- **Testing:** Pest (PHP), PHPUnit (PHP), Jest (JS), Playwright (E2E)
